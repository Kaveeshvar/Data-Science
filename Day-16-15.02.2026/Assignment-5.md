### Digital Wallet App - Paytm / PhonePe

#### 1️⃣ North Star Metric (NSM) - 
This is the single metric that reflects value created for users.

    Monthly Active Transacting Users (MATU)

    Total Transaction Volume (GTV)

    Number of Successful Transactions

#### 2️⃣ Activation Metric
This measures when a new user experiences product value for the first time.

    First successful transaction within 7 days

    First wallet load + transaction

    KYC completion + transaction

#### 3️⃣ Retention Metric
Measures continued value.

    % of users who transact again in 30 days

    7-day, 30-day retention

    Repeat transaction rate

#### 4️⃣ Monetization Metric
How the company makes money.

    Take rate (commission % per transaction)

    Revenue per active user (ARPU)

    Net revenue per transaction


**Acquisition → Activation → Retention → Monetization**
